This is an offline-first research application packaged inside an Android WebView. It is not a production brokerage service. Live feeds require separately verified provider access.

Five-step Android verification

1. Install the GitHub Actions debug APK, or open this HTML in Chrome.
2. Markets → install clearly marked SYNTHETIC data; verify four market categories and the saved dataset badge.
3. Intelligence → inspect RSI, EMA, MACD and candle chart, then open Strategy lab and run each strategy.
4. Paper desk → buy one virtual unit, sell it, inspect P/L, then reload the page to verify persistence.
5. Control room → export a backup. Check import/restore on a separate browser profile before you erase anything.

Architecture / limitations

Offline: All saved data, calculations, paper trades, charting, alerts on import and exports.

Online: Optional market-data requests to Frankfurter, Coinbase, Twelve Data or CryptoCompare. Availability depends on internet, CORS and provider entitlements. Data may be delayed.

No broker integration: This application cannot trade your real account. It does not contain an AI model or claim high-certainty predictions. For real trades a separate secure server, broker API, identity verification, cybersecurity review and applicable legal approvals are required.

Public API resources: Twelve Data documentation · Frankfurter · Coinbase Exchange · CryptoCompare documentation.
