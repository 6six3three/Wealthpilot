# Zenvora WealthPilot Green v7.4 — web app
This is a mobile-first Progressive Web App with offline wildlife images. Finance and investment balances are DEMO only.
To publish: GitHub repository Settings → Pages → Deploy from a branch → main → /(root) → Save.
Once GitHub reports deployment, open https://6six3three.github.io/Wealthpilot/ in iPhone Safari and tap Share → Add to Home Screen. On Android Chrome choose Install app / Add to Home Screen.
The first online visit installs the offline app shell. Owner vault requires secure HTTPS and persistent browser storage. Data on one device does not sync automatically with another.
Do not enter confidential ranger patrol routes, sensitive species coordinates or incident intelligence on a public prototype.
This package is not an Apple App Store IPA.
